Module 14 — live verification run
=================================

Everything below is the API's own output, captured by scripts/m14-verify.sh
against a real Laravel server on a real MySQL 8 database. Nothing is
transcribed and nothing is stubbed.

A note on the ownership check near the end. It sends another customer's token
to this customer's checkout id and gets a 404 — but the journey in the path
belongs to the first customer too, so trip ownership refuses before the quote
lookup is ever reached. That is the right answer for the wrong reason to be
quoted as evidence of quote scoping. Quote ownership is measured properly in
CheckoutApiTest, where the second customer has their own journey and their own
cart, and where removing either clause of the scoping query was watched to open
the hole.
